# v0.1.6b1

Released: 2026-08-12

> [!IMPORTANT]
> This is a beta release for evaluating the Go runtime migration. Whether this
> implementation will be promoted to a stable release is still under review.

- Replaced the Python/FastAPI HTTP server with a standalone Go server. This
  proxy does not require a Python web runtime, and the Go implementation reduces
  idle memory use and starts substantially faster under the recorded local
  benchmark.
- Kept the Python package only as a dependency-free `uvx` launcher and as an
  `openai-python` compatibility-test client. Supported wheels transparently
  replace the launcher process with the bundled Go executable.
- Added Responses, Chat Completions, Models, Images, Audio, stored-object,
  fallback proxy, daemon, auth, configuration, redaction, and streaming behavior
  to the Go runtime.
- Added deterministic Go HTTP/SSE contracts, fuzz tests, spawned-binary E2E,
  `openai-python` process contracts, and opt-in real Codex live matrices.
- Added native installed-wheel E2E on Linux, macOS, and Windows for x86_64 and
  ARM64. CI exercises the packaged launcher, Go server, API request, and process
  lifecycle against synthetic auth and a local fake Codex backend.
- Published wheels bundle the Go executable for Linux x86_64/ARM64, macOS
  Intel/Apple silicon, and Windows x86_64/ARM64. There is no Python server
  fallback and no source distribution for unsupported platforms.
- Hardened release builds against generic wheels, source archives, stale package
  files, empty binaries, and mutable Go module metadata.
- Changed Docker images to run the static Go executable directly as a non-root
  user without Python in the runtime image.
