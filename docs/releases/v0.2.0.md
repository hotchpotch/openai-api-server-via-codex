# v0.2.0

Released: 2026-08-13

> [!IMPORTANT]
> This is a breaking runtime release. The Python/FastAPI HTTP server and Python
> fallback have been removed. The Python package remains only as a small
> dependency-free `uvx` launcher for the bundled Go executable, plus SDK test
> and release tooling.

## Go server runtime

- Replaced the Python HTTP server with a standalone Go server while preserving
  OpenAI-compatible Responses, Chat Completions, Models, Images, Audio, stored
  compatibility objects, fallback proxy routes, streaming, tools, structured
  outputs, image input, and `previous_response_id` behavior.
- Reduced idle RSS from about 59 MiB to 8.3 MiB and peak RSS from 261–304 MiB
  to 18–20 MiB in the recorded Linux proxy benchmark. Startup fell from about
  330 ms to 10 ms. These figures measure proxy overhead; real model latency is
  dominated by the upstream Codex service.
- Preserved daemon commands, CLI/environment/config precedence, bounded stores
  and request concurrency, timeouts, graceful shutdown, and redacted request
  diagnostics in the Go runtime.

## Authentication and operations

- Kept Codex authentication preflight and refresh-token rotation, including
  writing refreshed credentials back to `auth.json`.
- Reloaded externally rotated credentials after an upstream `401` and retried
  once before any response stream reaches the client.
- Added stable reason codes and actionable messages for authentication
  failures, normal-mode logs for upstream `401` retry decisions and rejected
  incoming API keys, and tests preventing credential or response-body leakage.
- Restored one concise request-completion log per API request in normal mode
  while keeping routine `/healthz` probes quiet.

## Distribution

- Published native platform wheels for Linux x86_64/ARM64, macOS Intel/Apple
  silicon, and Windows x86_64/ARM64. Each wheel contains the matching Go
  executable; unsupported platforms must build from source.
- Added six standalone Go archives and reproducible SHA-256 checksums to GitHub
  Releases. Archive URLs and checksums are stable for Homebrew Formulae and
  other package managers.
- Changed Docker to a small non-root Alpine runtime without Python or the Go
  toolchain. Stable releases publish public `linux/amd64` and `linux/arm64`
  images to GHCR under both `v0.2.0` and `latest`.
- Added deterministic Go contracts, fuzz tests, spawned-binary E2E, official
  `openai-python` consumer contracts, six-platform installed-wheel CI, Docker
  verification, real Codex live matrices, and Raspberry Pi 5 ARM64 validation.

## Upgrading

- Existing `uvx openai-api-server-via-codex` usage continues to launch the
  server on supported platforms, now through the bundled Go executable.
- Python imports of the former server implementation are no longer available.
- Review custom process supervision, log parsing, and direct source installs.
  Use a platform wheel, standalone archive, Docker image, `go install`, or a Go
  source build for the new runtime.
- OpenAI SDK clients still use `OPENAI_BASE_URL=http://127.0.0.1:18080/v1`. The
  SDK requires a non-empty `OPENAI_API_KEY`, but the default local server does
  not authenticate incoming requests unless `--api-key` is configured.
